# 研究预印本

每个主题只有一份论文。相关证明按章节收在同一个 PDF，有可点击的目录；源文件、程序和证书归到该主题的复现材料。全部工作稿均未经同行评审。

| 论文 | 主要成果 | 复现材料 |
| --- | --- | --- |
| [平衡完全三部图的谱最近邻与秩](research/spectral-graphs/paper.pdf) | 解决猜想 20 与问题 21：证明两种谱距离下的最近竞争图均唯一，并给出尖锐的谱尾秩界。 | [材料](research/spectral-graphs/materials/) |
| [三条 Graffiti.pc 不等式](research/graffiti/paper.pdf) | 推翻 #138、#255、#256 三条不等式，并分别给出可达到的替代界。 | [材料](research/graffiti/materials/) |
| [A7 晶格的双点周期最优性](research/a7-lennard-jones/paper.pdf) | 证明每粒子体积为 1.076 时，A7 是双点周期 Lennard–Jones 晶体中的唯一最优构型。 | [材料](research/a7-lennard-jones/materials/) |
| [三维单位立方体的立方巡回](research/cubic-tour/paper.pdf) | 求得十一点时的精确最坏上确界 8√2，把任意点数的通用上界降到 16.10。 | [材料](research/cubic-tour/materials/) |
| [相切圆柱的半径与插入问题](research/tangent-cylinders/paper.pdf) | 构造八、九、十根相切等径圆柱，证明九柱半径小于 0.6453、十柱半径小于 0.619。 | [材料](research/tangent-cylinders/materials/) |
| [Farey 分支的收敛与逆恢复](research/farey-caustics/paper.pdf) | 证明收敛分支可由有序端点恢复，并给出一类仅凭无标签、零长度端点集也能唯一恢复的分支。 | [材料](research/farey-caustics/materials/) |
| [Gilbert–Steiner 网络的分叉度](research/branching-degree/paper.pdf) | 证明允许成本指数和需求比变化时，三维最优网络的分叉度没有统一上限；同时给出固定指数下的维数界。 | [材料](research/branching-degree/materials/) |
| [近线性分支运输的熵渐近](research/transport-entropy/paper.pdf) | 确定任意球内目标和相同平行切面在近线性极限下的首阶能量修正，给出均匀球体的精确系数。 | [材料](research/transport-entropy/materials/) |
| [加权 Bernoulli 不等式](research/weighted-bernoulli/paper.pdf) | 证明正权重不超过十个时，不等式对 0 ≤ p ≤ 1/3 的整个区间成立。 | [材料](research/weighted-bernoulli/materials/) |
